========================================
BiliUPMonitor v0.1.0  —  使用说明
========================================

Bilibili UP 主数据监控桌面工具
（Windows 10 / 11 · Tauri 2）

----------------------------------------
一、安装 / 运行
----------------------------------------

方式 A（推荐）：运行安装包
    BiliUPMonitor_0.1.0_x64-setup.exe
    按提示安装后从开始菜单或桌面启动。

方式 B：直接运行免安装版
    biliupmonitor.exe
    说明：
    - 该 exe 依赖系统 WebView2 运行时（Windows 11 已内置；
      Windows 10 若缺失，请先安装 WebView2 Runtime，或改用方式 A，
      安装包会自动补装 WebView2）。
    - 此 exe 主要供调试/备用，日常使用推荐安装包。

----------------------------------------
二、基本使用
----------------------------------------

1. 启动后点击左下角「＋ 添加订阅」；
2. 输入 B 站主页链接（https://space.bilibili.com/xxxxx）
   或纯 UID，点击「添加」；
3. 左侧切换 UP 主，右侧查看资料卡与最近投稿；
4. 视频列表顶部可切换排序字段（播放 / 点赞 / 在线 / 时间）
   与正序 / 倒序；
5. 点击用户名 / 头像 / 视频条目可打开对应 B 站页面。

----------------------------------------
三、系统托盘
----------------------------------------

- 点击窗口右上角 ×：默认「关闭到系统托盘」继续后台运行，
  不退出程序；
- 单击托盘图标：恢复并置前主窗口；
- 托盘右键菜单：
    · 显示 Bili Monitor
    · 立即刷新
    · 退出（真正结束程序）
- 设置页可改为「关闭按钮 = 直接退出程序」。

----------------------------------------
四、后台低功耗
----------------------------------------

窗口隐藏到托盘后自动进入低功耗模式：
- 在线人数：停止轮询；
- 视频播放/点赞/投币：约 30 分钟一次；
- 用户资料：最多 2 小时一次。
恢复主窗口后自动回到前台刷新频率。

----------------------------------------
五、数据保存位置
----------------------------------------

SQLite 数据库（自动创建，无需手动初始化）：
    %APPDATA%\com.biliupmonitor.desktop\biliupmonitor.db
包含：订阅列表、用户缓存、视频缓存、历史快照、应用设置。

----------------------------------------
六、已知限制（v0.1）
----------------------------------------

1. 部分 B 站接口对匿名请求有风控（-352 / -412），程序已内置
   备用接口与退避重试；偶发失败会优雅降级显示，不影响核心监控。
2. 「获赞 / 总播放」等字段匿名下可能显示「—」；
   如需完整数据，可在 设置 → 高级 中填写 B 站 Cookie。
3. 动态装扮编号（可选增强项）在部分网络下可能无法获取。
4. 第一版不包含登录客户端、评论区、下载、播放器、动态流、
   云同步等功能。
